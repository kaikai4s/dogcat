# 后台配置导入与导出

入口：后台 → 系统设置 → 配置导入与导出。仅超级管理员可访问，服务端的四个配置迁移操作也单独限制为超级管理员；普通后台配置查看权限不能导出。

## 操作步骤

1. 在测试环境打开入口，点击「导出配置 JSON」，将文件发送到微信文件传输助手。
2. 在正式环境打开相同入口，点击「选择配置文件并预览」，选择之前导出的 JSON。
3. 核对来源、目标环境、各类配置新增/更新数量。若预览涉及云文件，可导出素材清单，先将对应文件按相同目录上传到目标云存储。
4. 点击「确认导入全部配置」，再次核对环境后执行。成功后可导出本次导入前备份；页面会记住当前设备最近一次导入的备份编号。

文件按版本和校验和检查，最大768KB、400条配置记录，超出时明确拒绝，不导出截断文件，也不分段写入。校验和用于检查文件是否改动，不是数字签名；请只选择可信管理员从本项目导出的文件。

## 覆盖范围

- 系统设置中的业务参数：客服、首页、轮播、培训与题库、保证金和用品规则、邀请、佣金规则、订阅模板、官方账号展示、物流业务参数、活动规则等。
- 服务价格、服务打卡规则。
- 会员等级、优惠券模板、宠物头衔。
- 月度签到配置、抽奖活动定义。
- 商城分类、商品和规格配置。
- 问卷定义。
- 庄园地面尺寸、拼单及宠物照护规则、植物目录、建筑目录及土地解锁等级。

未配置的服务价格、打卡规则、植物与建筑目录会导出系统实际使用的默认配置。云文件转换采用当前已配置的测试/生产云存储根路径，包含普通图片、视频、商城图片以及庄园自定义素材，不止基础庄园素材。文件自身不包含素材二进制，不会自动上传或复制文件。

## 保留及合并规则

- 用户、宠物档案、订单、支付、退款、提现、收益、轨迹、聊天、答卷、用户优惠券、权限组、管理员账号等业务数据不在导出范围。
- 支付及转账配置不导出、不覆盖目标值。AI、物流及通讯等接口密钥不导出，导入后保留目标已有密钥。环境变量、数据库索引、安全规则、定时器和云函数部署不属于配置JSON。
- 同ID的配置合并；服务价格按服务key、打卡规则按服务类型/事件、会员等级按名称、签到按月份识别目标已有记录并维护引用。目标独有记录不会删除。
- 当前目标环境的库存、销量、优惠券已发数量、问卷统计及同ID抽奖奖项剩余库存保留。新增商品和奖项库存按文件初始化。新增问卷始终为草稿，不自动通知用户或发放奖励。
- 已有答卷的问卷不能通过迁移更换题目；已有商品SKU、抽奖奖项不能通过迁移删除。需要删除或重建时应先在对应后台核对业务影响。
- 生产环境强制关闭测试地址模式；庄园地面不能缩小到已使用宅基地范围以内。
- 导入不追溯修改既有会员、订单、优惠券或收益，也不触发发券、结算、转账或通知发送。

## 一致性与备份

预览不写配置。导入时在一个数据库事务内重新读取并校验目标配置，记录备份、写入全部变更和审计日志；任一步失败整笔回滚，目标发生并发变化时要求重新预览。导入请求ID防止网络重试重复执行。超出实际云环境的事务容量或执行限制时会失败回滚，不能用本地模拟测试替代真实环境事务验收。

备份保存于 `config_migration_backups`，不含支付、转账凭据或API密钥，可经超级管理员接口导出。导入前会初始化该集合；部署时应确保该集合仅允许云函数读写。备份JSON可按同样流程重新导入以恢复已有配置值，但合并模式不会删除首次导入后新增的配置，不能将其当作自动数据库全量回滚。

本功能支持同一小程序的跨云环境迁移，不允许跨AppID导入。不执行生产配置迁移或素材上传；需部署新版api与小程序，再用测试配置文件在目标环境预览验证。
