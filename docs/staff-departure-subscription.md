# 宠托师出发订阅通知

## 配置

部署 api 云函数并更新小程序后，进入管理员后台 → 系统设置 → 订阅消息，开启订阅消息，在「宠托师出发通知模板」填写模板 ID 后保存：

`Ok3GmyPJUxBvOWG7RdFVhBLrpbVMvkiY2-d-IlJPI_0`

使用微信模板编号 77732，字段必须对应：

| 微信字段 | 内容 |
| --- | --- |
| thing1 | 服务项目 |
| time2 | 当前服务场次的预约时间（北京时间） |
| time3 | 本次点击出发的时间（北京时间） |
| thing4 | 宠托师姓名 |

模板 ID 只从后台配置读取。缺少配置时，订单仍能正常出发，通知记录显示「尚未配置该通知模板 ID」。

## 用户授权与验证

1. 下单用户在订单详情点击「开启提醒」，或到订阅中心单独订阅「宠托师出发通知」。原有其他通知的授权不能代替这个新模板的授权。
2. 宠托师点击出发后，通知发送给下单用户，点击通知进入对应订单详情。同一场次重复或并发点击不重复发送，下一场服务可再次发送。
3. 订阅中心每次最多请求 3 个模板，更多模板需用户点击「继续订阅」。拒绝、关闭或过滤授权均不显示为已同意。
4. 在后台订阅消息页查看发送记录、失败或跳过原因；修正配置或由用户重新订阅后，可对失败或跳过记录点击「重试」，由现有通知重试任务处理。

一次性订阅需要足够授权次数。自动回归使用模拟微信发送接口，真实送达仍需在已配置模板的微信环境中完成一次用户授权和出发验收。
