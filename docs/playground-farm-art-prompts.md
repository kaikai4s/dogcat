# 菜园素材生成提示词

以下提示词可直接分别复制。先生成土地并选定风格，再把选中的土地和现有游戏截图作为后续作物的风格参考。土地与作物分开出图，游戏里叠加，便于同一块土地换种作物。

## 统一规格

- 土地：3张独立透明PNG，每张256×256，分别为待开垦、已开垦、已浇水。
- 作物：每种一张4列1行的阶段图集，共6张；每张1024×256，每格256×256。顺序：萌芽、幼苗、生长、成熟。
- 镜头：固定等距俯视，地面菱形宽高约2:1，光照来自左上；同一画风、同一镜头，无透视近大远小。
- 所有单格的地面中心/植株根部固定在像素(128,192)，不要随阶段移动。土地菱形约224×116，中心(128,192)。
- 作物不自带整块土地，根部与土地中心重合。保留真实成长比例，幼苗小、成熟大，不能把每阶段都放大到一样高。
- 每格留透明边距，主体不越格；真实RGBA透明，禁止画棋盘格充当透明。若生成工具不支持透明，改用纯白背景，保持完整深色轮廓，之后可抠图。
- 不要文字、编号、水印、UI、边框、花盆、人物、宠物或无关场景。不要把多个阶段融合成一株。

## 土地：待开垦

```text
为温暖治愈的2D等距视角宠物农场游戏制作一张“待开垦土地”素材。精致手绘游戏精灵，柔和自然色彩，细而清楚的深色轮廓，光源在左上，与参考游戏的庭院和角色保持同一种画风。固定等距俯视，无透视变形。画布256×256，真正透明RGBA背景。只画一块平贴地面的完整菱形地块，菱形宽224像素、高116像素，中心固定在(128,192)，四角大约(16,192)、(128,134)、(240,192)、(128,250)。地面是浅褐色的原生泥土，稀疏短草、少量小石子和轻微土粒，表现“可以开垦”，中央可清楚看见土地。外轮廓干净，边缘少量自然草芽；不要高起的方盒厚边，不要悬浮岛，不要整片草原，不画作物、人物、工具。保持完整边距，不裁断四角。无文字、无数字、无网格、无水印、无背景填充、无外框。
```

## 土地：已开垦

```text
参考上一张“待开垦土地”的镜头、菱形边界、大小、画风和左上光照，制作同一块地“已经开垦、尚未播种”的状态。画布256×256，真正透明RGBA背景。地块必须与参考逐像素对齐：菱形宽224、高116，中心(128,192)，四角约(16,192)、(128,134)、(240,192)、(128,250)。去掉杂草和石块，替换为温暖深棕色的松软耕土，清楚而柔和的平行细田垄，田垄沿等距地面方向排列，有少量自然土粒，中央留出可叠加作物的位置。是平贴地面的可种植土壤，不是木箱、花盆或悬浮土块。保留与参考一致的土地轮廓，不要增大或旋转。无作物、人物、工具、文字、数字、水印、棋盘背景和边框。
```

## 土地：已浇水

```text
以参考的“已开垦土地”为基础，只改变土壤湿润状态。温暖治愈的2D等距农场游戏素材，镜头、画风、菱形边界、田垄和左上光照保持一致。画布256×256，真正透明RGBA背景。菱形宽224、高116，中心(128,192)，四角约(16,192)、(128,134)、(240,192)、(128,250)。耕土变为自然深褐色的湿润土壤，田垄保留，少量柔和湿润反光即可；不要大片水洼、蓝色海面、漂浮水滴图标或夸张高光。无作物、人物、工具、文字、数字、水印、棋盘背景和边框。不要移动地块或改变轮廓。
```

## 作物图集通用要求

以下每段均为一张完整图集的提示词。生成后交付原图；不必自行把幼苗放大或按阶段重新居中。

## 胡萝卜：4阶段

```text
制作治愈系2D等距农场游戏的“胡萝卜生长阶段”透明精灵图集。精致手绘、柔和自然配色、细深色轮廓，匹配参考土地画风，固定等距俯视、左上光照，无镜头变化。总画布1024×256，严格4列1行，每格256×256，背景真正透明RGBA。每格植株根部固定在本格(128,192)，保留自然成长比例；成熟株高也不超过176像素，四周留边。左至右：1. 刚破土的一对微小嫩绿子叶；2. 小型胡萝卜幼苗，几片细嫩羽状叶，尚无明显橙色根肩；3. 茂盛但未成熟的羽状绿叶，根部只露很小的橙色根肩；4. 成熟胡萝卜，饱满茂盛的羽状叶，地面根部可见一小段橙色根肩，主体根仍在地下，不要整根悬空胡萝卜。四格是同一品种同一镜头的成长过程，不是四种不同作物。只画植株，不带整块泥土、不带花盆、无人物工具、无文字编号水印、无网格、无格子边框、无烘焙棋盘背景。严格不跨格，不能把每阶段画成同样大。
```
