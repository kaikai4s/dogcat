## 后台操作

入口：管理后台 → 营销与会员 → 农作物管理。超级管理员直接可用；普通管理员需要在用户组与权限中分配“农作物管理”的查看、上传、发布权限。

1. 新增作物，填写唯一编号（小写字母开头，最多40位小写字母、数字、下划线或横线）及名称。已创建的编号不可修改。
2. 设置生长分钟数、种子价格、每份出售价格、基础收成、收获经验、解锁等级。金额单位是农场金币。
3. 填写阶段开始进度，例如 `0,20,65,100`。支持2至8个递增整数百分比，首项必须0，最后必须100；最后一格只在成熟后显示。
4. 上传单行透明 PNG 图集。各阶段从左至右排列；列数等于阶段数；每格128、256或512像素正方形。落脚点统一在每格宽度50%、高度75%。不要上传 JPG、GIF、截图、重复土地背景或不透明底图。可从微信聊天文件或相册选择原图，最大8MB。后台验证 PNG 编码、透明度、各格内容和尺寸。
5. 预览阶段，点击“保存并发布”。同一配置被其他管理员修改时需返回列表刷新后重编，防止覆盖别人的修改。最多32种作物。

后台上传会自动分配新路径，无需手工改文件名或复制 fileID：

```text
packagePlayground/2d/baseImage/farm/custom/<作物编号>/<随机版本>.png
```

上传只保存图片；点击“保存并发布”才会更新配置。配置保存在 `platform_configs/playground_farm_catalog_v1`，不需要手工编辑数据库。土地图片目前使用固定配置。

## 同步与交易规则

用户进入庄园、打开菜园或交易时读取最新配置；停留场景期间约每30秒刷新一次配置，网络失败会重试。保存作物配置后，符合等级条件的用户可在种子商店购买并在自己菜园播种，不会自动种满土地。

购买和出售价格以服务器当前配置为准，客户端不能改价。播种时保存当批次的生长时长、基础收成和经验，后续改配置不改变已播种批次；旧版已种作物保留原始参数。浇水和施肥仍按原规则加速并增加收成。

下架会停止购买和播种；已经种下的作物仍可照料、收获，仓库已有作物仍可出售。修改后的图片和作物名称可同步到已有地块。不要删除仍被使用的云素材。

## 后台定位

微信平台的接口审批和隐私声明，与用户手机的定位授权是独立条件。本次增加了开始采集前的手机授权检查、失败详情和“定位授权设置”入口。仅在 `startLocationUpdateBackground` 原生接口成功后显示后台采集；失败时保留原始错误，并尝试前台连续采集。

真机服务中的订单上点击“定位授权设置”，允许使用小程序期间和离开后获取位置，并确认手机系统定位开启、微信有系统定位权限。返回后页面会停止旧采集再重试。若微信只允许使用期间定位，离开页面后前台采集会暂停。关闭微信、结束小程序或系统回收进程也可能中断后台采集。

如果仍失败，记录页面完整的 `startLocationUpdateBackground:fail ...`、微信版本、手机系统及当前小程序版本，区分设备授权、系统开关、接口权限和旧版本配置问题。开发者工具和自动化模拟测试不能证明真机后台定位已经恢复，也不能仅凭接口审批完成确定原故障原因。
