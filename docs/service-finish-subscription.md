# 服务完成订阅通知

管理员后台 → 系统设置 → 订阅消息 → 服务完成模板，填写微信模板编号 18325 对应的模板 ID。模板 ID 只通过后台配置，不写死在代码中。

| 字段 | 内容 |
| --- | --- |
| character_string14 | 服务订单号 |
| thing6 | 服务项目，最多 20 字 |
| thing5 | 本场完成、最终完成或平台核实完成提示，最多 20 字 |
| time3 | 本场实际完成时间（北京时间） |

正常完成、多天订单每场完成、系统自动完成均向下单用户发送通知。管理员核实完单同样发送，使用平台核实完成的时间；该时间不声称是线下实际离场时间。系统自动最终完单保留原有宠托师完成提醒。

状态更新与通知入队在同一事务完成，同一场或最终完单不重复发送。重试保留原完成时间。催促尚未结束服务使用服务进度模板，不再使用完成模板。

用户在订单详情「开启提醒」或订阅中心同意服务完成通知。服务中订单的授权入口优先请求完成、进度和开门通知。更换模板 ID 后用户需要重新同意新模板。

历史待发记录仅在能确定实际完成时间时转换字段；缺少时间或属于催促记录时跳过并保留原因，避免填入预约时间或重试时间。

发布时需部署 api 并更新小程序，配置 18325 模板 ID。自动回归使用模拟微信接口，真实送达须在微信中完成授权及完单验收。
