# 第十版：行走与待机候选

范围：男角色、左前方（sw）。本轮重新生成完整行走与待机图，不移植手掌，不局部调色，不通过程序扭曲肢体或补出动作帧。尚未接入正式园区，其余角色和方向尚未扩展。

通过 imagegen 技能自带 CLI，使用用户提供的兼容接口请求 `gpt-image-2.6-sunburst`。模型 ID 是请求值，不代表已独立验证供应商内部模型映射。凭据只读取项目已忽略的本地文件，不写入脚本或文档。

本轮共六次请求。首轮 12 帧行走和待机存在重复步态、后排人物缩小问题；第二轮八帧行走和骨架引导行走仍未清楚呈现左右腿交换，均未选用。最终行走使用第五版图集约束姿势、第五版待机首帧约束人物形象，完整重绘；待机采用本轮重新生成的八帧版本。

最终提示词：

- `prompts/walk-preserve-approved-poses.txt`：保留八帧不同姿势与前后遮挡，重新完整绘制人物、浅金白色双手与连续手腕。
- `prompts/idle-refined.txt`：双脚落地、轻柔呼吸、披风和飘带摆动，保持统一人物比例。

最终文件位于 `output/imagegen/pet-memorial-v10/`：

- `raw/walk-preserved.png`、`raw/idle-refined.png`：最终采用的原始模型输出。
- `cloud-upload/walk-sw.png`、`cloud-upload/idle-sw.png`：透明运行图集，均为 1024×512，4 列×2 行，每格 256×256，共八帧。
- `frames/walk/`、`frames/idle/`：独立透明帧。
- `walk.gif`、`idle.gif`、`actions-preview.gif`：循环预览。
- `preview.html`：园区实景、按住移动/松开待机、大小调整、暂停、逐帧、半速、浅深底检查及手部放大。
- `manifest.json`、`verification.json`：参数、来源哈希和文件校验。
- `boy-sw-actions-v10.zip`：运行图集、独立帧、预览、说明与提示词，不含未采用试制原图。

后处理脚本：`scripts/assets/package-memorial-v10.py`。保留模型输出的真实 Alpha，采用跨动作统一比例，按头部中心做整帧水平平移。10.1 修正了用户指出的行走一高一低：原来按每帧最低鞋底做竖直对齐，换脚时前后脚的透视高度差导致整个身体上下跳动。行走现改为按共同头部高度做整帧竖直平移，保留源图肢体形状和脚的相对位置；待机仍按固定脚底对齐。不是逐帧独立缩放，也没有改变肩臂、手掌或腿脚。运行锚点为 (128, 230)，行走脚底不再被强行压在同一屏幕横线上。行走预览每帧 140ms，待机每帧 320ms；实景行走按实际位移推进动画相位。`walk-stability-comparison.gif` 保存修正前后对比，`comparison/walk-before.png` 保留旧图集，检查文件记录每帧修正量和前后头部高度。

此页用于素材审阅，只支持当前左前方朝向与一段预览移动范围；不是园区寻路、碰撞或完整四方向控制的实现。地面阴影由预览单独绘制，不烘焙到角色图集中。正式接入仍需补齐其余方向并检验微信端加载、透视比例与遮挡。

视觉审查仍需关注慢速播放中的膝盖起伏、指尖稳定性与停步瞬间的姿势变化；通过透明边界和切片校验不等于动作已获用户验收。原始八帧保留其真实细节变化，没有通过补帧或模糊掩盖。
