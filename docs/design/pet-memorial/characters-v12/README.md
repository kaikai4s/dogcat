# 第十二版：女生四方向动作与男女合并预览

本轮补齐女生左前（sw）、右前（se）、左后（nw）、右后（ne）的行走和待机候选，共八张透明图集、64 帧。女生以 `source/character-girl-reference.png` 为身份依据，保留金色长发、无五官的发光面部、贴身金白服装、披风及飘带。男生沿用第十一版，不重新生成。

`output/imagegen/pet-memorial-v12/preview.html` 可切换女生/男生，分别查看四方向行走和待机、按住方向移动、松开保持朝向待机、半速、逐帧、浅深底以及手腕/膝脚细节。合计 16 张图集、128 帧。此页是素材审阅预览，不是正式园区实现。

## 输出

- `cloud-upload/{walk|idle}-{sw|se|nw|ne}.png`：女生八张透明图集。
- `frames/{direction}/{action}/01.png` 至 `08.png`：女生 64 张独立帧。
- `boy/cloud-upload/`、`boy/frames/`：男生上一版图集和独立帧，复制后逐像素一致。
- `four-directions.gif`：女生四方向行走/待机循环；`boy/four-directions.gif` 为男生。
- `manifest.json`、`verification.json`：女生来源、参数、哈希与切片检查；`boy/` 下保存男生对应记录。
- `girl-four-directions-v12.zip`：包含女生及 `boy/` 男生文件的合并素材包，含预览、参数、独立帧和提示词。
- `raw/`：本轮模型原图与未采用试制，未加入 ZIP。

每组 8 帧，4 列×2 行，单帧 256×256，图集 1024×512，锚点 (128,230)。行走默认每帧 140ms，待机 320ms。园区预览按实际移动距离推进步态。

## 生成与处理

使用 imagegen 技能自带 CLI edit，请求用户此前提供接口的 `gpt-image-2.6-sunburst`。该名称是请求模型 ID，供应商内部模型映射未独立验证。凭据仅从已忽略的本地连接配置读取。

初次八组请求使用女生原图作为身份参考、对应男生图集作为方向和姿势引导，全部人物由模型重新绘制。检查发现右前、右后行走误带宽松裤型，随后四组行走均再以女生对应待机为造型参考完整重绘，使贴身衣装与鞋靴尽量保持一致。最终提示词为 `prompts/walk-{direction}-refined.txt` 和 `prompts/idle-{direction}.txt`；初轮行走提示词与原图保留为制作记录。

`scripts/assets/package-memorial-v12.py` 保留真实 Alpha，使用统一比例、整帧水平定位，行走以头部基准稳定高度，待机按脚底对齐。没有移植手部、局部调色、关节变形或程序补帧。检查源图切片边界、透明边界、八帧唯一性、图集与独立帧逐像素一致及行走头部高度范围。

## 当前边界

女生四方向素材是可审阅候选，文件校验不等于视觉验收。长发与披风的柔光、发丝和指尖稳定性、不同动作间服装纹理、换脚及停步姿势仍需结合预览审阅。没有制作跑步和互动动作；未上传云端，未接入正式园区，也未发布。
