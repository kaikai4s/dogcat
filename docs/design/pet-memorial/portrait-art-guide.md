# 宠物画像制作与平台安放

当前园区使用 2D Canvas。上传照片制作 2.5D 风格的静态宠物精灵，成品是透明 PNG。主人申请时选择“乖巧坐着”或“安心趴睡”；后台复制提示词会自动匹配该申请的姿势。旧申请默认坐姿。

## 坐姿提示词

```text
请参考我上传的同一只宠物的正面照和侧面照，制作一张用于宠物纪念园的全身画像素材。
风格：温柔精致的 2.5D 手绘游戏精灵，柔和体积感、低饱和自然色彩、细腻毛发。采用平行投影，约 30 度俯视、正面偏左的四分之三视角，面朝画面左下方，光源来自左上方。
忠实还原参考照片中的品种、毛色分区、花纹、脸型、耳形、尾巴和体型，不能替换成普通同品种模板。仅一只宠物，全身完整、比例自然。
姿势：乖巧自然地坐着，前爪落在同一接地平面，后腿自然收拢，尾巴完整自然地放在身体旁，眼神温柔。四肢结构准确，不要画成站姿或趴姿。
输出正方形 512×512（也可 1024×1024）的 8 位 RGBA 静态 PNG，真正透明背景，关闭隔行扫描。坐姿主体占画面高度约 70%～80%，宽度由真实比例决定。主体水平居中，四周保留透明边距，耳朵、脚掌、尾巴和毛发不能裁切。接地部分保持自然平稳。
只画宠物本体；不画墓碑、平台、底座、地面、环境、草地、道具或投影。不要文字、水印、边框、拼贴、多视图、棋盘格、白底、灰底、黑色厚轮廓、额外肢体或拟人化装饰。
用于 2D Canvas 中的静态展示，呈现 2.5D 视觉效果。最终提供保留透明通道的 PNG 原文件，文件不超过 10MB；从相册上传时系统自动整理尺寸。
```

## 后台操作

1. 时光小筑审核 → 宠物画像，查看主人选择的姿势、正面/侧面参考照和特征备注。
2. 复制对应姿势的提示词，在制作工具中上传参考照并生成成品。按照片核对毛色、花纹、肢体与姿态。
3. 建议导出 512×512 或 1024×1024 的静态透明 PNG 原文件；相册原图可达 10MB，每边不超过 4096 像素。纯白底、棋盘格背景不等于透明。
4. 点击“从手机相册上传画像”。系统保留透明通道，按比例整理到 512×512 画布并控制上传大小，不会裁切或拉伸宠物。若系统已将原图转成 JPEG，请重新下载并保存透明 PNG，不要截图。
5. 上传后服务端检查 PNG，并计算非透明像素的外接矩形。页面显示该小筑实际样式与平台上的安放比例，含旧版小平台适配。
6. 通过“缩小 / 放大 / 默认”调整到 50%～140%，每次 5%；脚掌或趴姿身体底部始终贴在平台上，宽高等比例变化。预览加载失败时不能确认安放。
7. 确认窗口再次展示合成效果与大小；通过后使用相同参数进入园区。服务端重验图片像素摘要，防止预览后文件被替换，并保存不可变成品副本。

## 自动适配范围

- 新上传成品按真实透明轮廓去掉四周留白后，等比例容纳在平台前部的展示区域；坐姿按高度、横向趴姿按宽度优先约束。照片里宠物偏左、偏小或不同分辨率不会直接影响显示大小。
- 主体本身必须完整且背景真正透明。系统识别的是非透明轮廓，不能自动区分宠物与附带的地面、阴影、文字，也不会修补裁掉的耳朵或爪子。画面中只保留宠物本体。
- 宠物位置固定在平台内；缩放改变大小，不会把主体移到草地外或拉伸体型。后台与园区共用布局计算；园区缩小纹理缓存时会按实际纹理分辨率换算裁切坐标。
- 已经安放的旧素材保持原有 88% 接地锚点；申请更新并重新上传后使用新的自动适配规则。
- 后台合成预览展示真实平台素材与安放比例，背景为示意草色；园区远近缩放、周围树木和人物遮挡以实际场景为准。

## 发布

需一并更新 API 云函数和小程序代码；无需新增数据库索引或为本功能重新上传平台素材。图片预检复用 memorial.preparePortraitAsset 的权限，传入当前 uploadId/fileId 时返回裁切元数据和像素摘要；确认接口按原文件重算轮廓，只接受 50%～140% 的大小。
