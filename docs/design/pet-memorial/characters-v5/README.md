# 男角色左前方：行走修手与待机

用户已认可第四轮行走动作，本轮保留其步态，仅修复手部，并新增待机。模型请求参数均为 `gpt-image-2.6-sunburst`，通过 imagegen 技能自带 CLI 图片编辑调用用户配置的兼容接口，共两次请求；供应商内部模型映射未独立核实。

## 文件与播放

- `walk-sw.png`：8 帧行走，单帧 312×416，4 列×2 行，每帧 125ms，共 1 秒。
- `idle-sw.png`：8 帧待机，单帧 312×416，4 列×2 行，每帧 300ms，共 2.4 秒。
- `frames/walk/`、`frames/idle/`：逐帧 RGBA PNG。
- `preview.html`：动作切换、暂停、逐帧、半速、底色切换和手部放大。
- `walk.gif`、`idle.gif`：草绿色背景循环预览。
- `manifest.json`：尺寸、帧时长、检查数据及处理记录。

## 手部修补

原有手部被简化为浅色小块，部分与袖口或披风融合。放大躯干区域后让模型补手掌、拇指、手指与腕部。将结果映射回原帧，仅通过局部羽化遮罩替换手部和腕部像素。遮罩外的头部、身体、腿与脚逐像素保持原样；没有拉伸腿或重做已确认的行走。

输入 `walk-hand-edit-target.png`；完整提示词 `prompts/walk-hands.txt`；模型输出 `raw/walk-hand-details.png`；修补遮罩 `walk-hands-patch-mask.png`。

## 待机

使用用户认可的行走角色图作为身份与服装参考生成八帧慢呼吸，伴随披风和飘带轻摆。双手垂放，双脚落地。为消除模型造成的靴面细节闪动，将所有帧 y≥284 的靴子像素锁定为生成的第 1 帧，在 y=272..284 的小腿上部交界处渐变衔接。上半身、披风和头发使用模型生成的帧；没有程序形变或插值造动作。

完整提示词 `prompts/idle.txt`；原始输出 `raw/boy-idle-sw.png`。

## 检查与范围

两套均为 8 个不同帧、真实透明 Alpha，Alpha>32 的主体边界未触碰单元格。行走遮罩外像素完全相同；待机靴子区域 8 帧逐像素相同。逐帧检查了手与袖口连接、脚尖和披风边界。透明像素与帧差检查不代替用户对自然程度的判断。

本次只完成男角色左前方。尚未接入正式园区；女角色及其余方向未在本轮制作。历史动作的步幅和服装样式按用户认可的版本保留。
