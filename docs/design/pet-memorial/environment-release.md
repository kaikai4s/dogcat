## 时间、天气和季节

- 全部日历计算使用 UTC+8 的北京时间，不依赖手机时区。通过 world、加入园区和人物同步响应中的服务器时间校准手机时钟；无新增轮询请求。忽略无效、倒退或耗时超过 10 秒的网络时间样本。
- 清晨、白天、黄昏、夜晚自动过渡；冬季夜晚更长、夏季白天更长。这里使用北京时间的美术时段，并非用户所在地的天文日出日落。
- 春季为 3–5 月，夏季 6–8 月，秋季 9–11 月，冬季 12–2 月；换季首周逐步混合草木颜色。
- 天气由园区 ID 和 90 分钟时间段确定，同园访客共享结果；开始后的 12 分钟平滑衔接上一时段。连续时段可能维持同种天气。
- 春季花瓣与嫩叶、夏季绿荫和夜间萤火、秋季暖叶、冬季霜色与轻雪；雨、云和雾按季节概率出现。属于园区模拟天气，无位置授权和真实天气接口。
- 夜间增加路边、亭屋和泉水附近的暖灯；地图、路线和操作控件保持可读。
- 设置里可关闭雨雪、飘叶和动态雾气，选择自动保存；静态四季草木和昼夜光照继续显示。
- 四季图集非阻塞加载，失败时保持基础树木并可在设置中重试。

## 后续补充：可互动草坪（2026-11-12）

草坪增加六叶小草簇和三层深浅配色，草根按世界坐标确定，换季时配合已有环境变色。风动使用逐帧时间，避免环境信息每秒更新造成草叶跳动。脚边草叶向两侧拨开并压低，离开后阻尼回弹，约 2.4 秒清除作用记录；脚前少量草叶绘制在鞋边，增强接地感。

附近其他访客使用已经插值的人物坐标触发草叶，没有增加同步请求。断线重连、传送、大地图与前后台切换会避免或清除虚假长轨迹。草叶避开石路、泉台、建筑和小筑平台，新增/释放小筑后遮罩随之更新，不修改碰撞或申请格子。

程序生成草叶姿态图集，最多一张 1024×624 Canvas（约 2.44MiB），只缓存用到的弯曲姿态。每帧最多 1200 个可见草簇，根数据最多 40 块，踩踏记录最多 2400 条；全景及宽视野省略草叶细节。不支持离屏画布时使用批量路径绘制。关闭环境特效时停止风吹，保留脚步拨草。

本次不新增下载素材和云接口；此前四季资源已上传的环境仅需重新编译/发布小程序。
