# 第四轮步态优化样片

模型请求参数：`gpt-image-2.6-sunburst`；调用方式：imagegen 技能自带 CLI 图片编辑。共六次请求，保存于 `raw/`；不代表独立验证了供应商内部模型映射。

本轮改用带现有头部、躯干、披风与指定四肢位置的粗略姿势参考，先试制两个相反接触姿势，再生成八帧并修整。最后一次修正了姿势参考本身的支撑腿长度、步幅和抬脚高度。

当前展示 `raw/boy-walk-sw-v2.png`。实际返回 1248×832、RGBA；4×2 排列，单帧 312×416。`frames/`、`walk-review.gif`、`contact-sheet.jpg` 来自原图等分，没有拉伸肢体、逐帧缩放或插值补动作。

观察到的改善：摆臂变化更清楚、左右腿交替、支撑时下蹲减轻。仍存在鞋形与角度变化、衣服下摆偏离原图、远侧手臂可见性不稳定。未完成正式场景中的循环衔接和支撑脚滑动验收，不能当成生产图集。

`preview.html` 提供本轮与第三轮的同步循环、暂停、前后单帧、半速及底色切换。浏览器自动打开本地 file URL 被工具安全策略拒绝，未绕过。

最终生成提示词见 `prompts/walk-final.txt`，输入参考为 `walk-paintover-guide-v2.png`。粗略参考仅用于约束模型，不是交付角色。完整检查记录见 `review.json`。
