# 四季草木技术与美术约束

沿用园区现有柔和写实、绘本质感的 2.5D 正交素材。树冠保持团簇轮廓和内部明暗，树干维持暖棕色；道路与小筑作为主要视觉焦点，装饰颜色不夺目。

| 项目 | 约束 |
| --- | --- |
| 渲染 | 微信小程序 Canvas2D，正交平行投影，统一世界比例 |
| 图集 | RGBA PNG，512×1024；2 列×4 行，每格 256×256 |
| 列/行 | 树、灌木 / 春、夏、秋、冬 |
| 锚点 | 每格归一化 (0.5, 0.84)，与原 props.png 一致 |
| 场景尺寸 | 树 150×186，灌木 64×64 世界单位，不随季节变形 |
| 内存 | 图集解码约 2MiB；原图轮廓与每格 alpha 完全一致 |
| 色彩 | 春绿与少量淡粉；夏季保持原图；秋季赭黄与暖橙；冬季灰绿与霜白 |
| 装饰 | 细小花瓣、落叶、霜点位于已有植被根部范围，不占用小筑或摆放区 |
| 动画 | 缓慢风动、稀疏雨雪，无大幅抖动、闪烁、全屏模糊 |

使用 `build-memorial-seasons.py` 对已有源图确定性重着色，alpha 逐字节验证。夏季直接复用原色。所有像素来源及使用限制沿用原园区素材，未引入外部图片和新生图调用。

已查看 `contact-sheet.png`，并在原生尺寸页面中检查四季、清晨/白天/黄昏/夜晚、雨雪与横屏。图集可用于本地预览和待上线验证；微信真机显示和资源读取仍需发布环境确认。
