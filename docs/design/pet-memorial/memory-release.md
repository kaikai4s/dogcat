## 私有媒体规则（上线前必须合并）

`cloudfunctions/api/storage-rules/memorial-memory.fragment.json` 仅是本功能的规则片段，不是整个存储桶的替换配置。
合并到现有规则时，必须优先处理 `memorial-memories/` 前缀，避免现有“所有用户可读/创建者可写”等宽松条件旁路：

- `memorial-memories/uploads/`：仅上传者可读写。
- `memorial-memories/vault/`：客户端读、写均为 false；仅云函数管理权限可访问。
- 其他路径沿用原规则。

客户端先申请随机上传凭证，再上传暂存文件。云函数校验身份、文件类型/大小、图片内容安全后，将已校验的字节另存为随机 vault 路径；保存回忆只接受属于当前主人和当前小筑的完成凭证。管理员通过后才发布该版本。
详情接口为获准查看者生成短时访问 URL。关闭公开立即停止向新访客提供故事及链接；已经发出的 URL 仍可能在平台有效期内可用（请求的 maxAge 为 600 秒），已下载的内容无法撤回。正式环境应验证实际签名过期行为和域名配置。

故事没有业务字数上限，编辑器显示 Unicode 字符计数；超过 16000 UTF-8 字节时文字保存到私有不可变文件，审核通过后发布对应版本。仍受云函数请求体、响应体、内存及执行时长等平台限制，极长内容需真机与云端验证；不是无限容量承诺。文本分段安全检查保留边界重叠。媒体限制：12 张图片（自动压缩至 900KB/750px），6 段视频（每段30MB），1首音乐（10MB，MP3/M4A/WAV）。视频/音频由管理员完整试听/观看后手动审核。

目前不会自动清理未被保存的上传及旧版本文件，以免误删用户回忆；需结合留存策略安排存储清理。

## 宠物画像

- 主人打开自己的回忆页，选择“申请专属宠物画像”，选择“乖巧坐着 / 安心趴睡”，分别上传正面照、侧面照，可附 500 字特征备注。
- 未完成的画像申请只有一份，待处理时不可重复更改；被退回后可重新提交，已安放后可申请更新。
- 审核后台新增“宠物画像”队列。分组管理员需要 `memorial.listPortraitsAdmin`、`memorial.preparePortraitAsset`、`memorial.reviewPortrait` 三项权限；超级管理员默认可用。首页待办包含三类申请数量。
- 审核员查看两张参考照，复制页面的制作提示词，在自己的制作工具中生成 / 修整透明图片，通过“从手机相册上传画像”选择透明 PNG 原图（≤10MB、每边≤4096 像素），系统自动保留透明通道并等比例整理到 512×512，上传后显示对应小筑平台的合成预览，可按 5% 步长在 50%～140% 调整大小；确认窗口再次展示效果后安放。建议制作 512×512、1024×1024；上传端统一导出静态透明 PNG，控制在 900KB 以内。服务端仍限制成品≤1MB，并检查完整 PNG、CRC、像素可解码、透明像素与非空主体，并做图片内容安全检查。花纹相似度、姿态、边缘质量和脚掌位置需审核员目视确认。
- 当前园区是 2D Canvas，使用 2.5D 绘画风格的静态精灵，不接收 GLB / FBX。无需更换整张园区素材。通过后自动绑定对应小筑，并通知在线访客刷新。
- 原参考照和草稿不进入公共地图；成品通过后公开，旧成品在重新申请 / 驳回时保留。长文本、参考照和最终成品都沿用上面的私有存储规则，必须合并配置。
- 新画像按服务端解析的非透明轮廓等比例适配平台，保存裁切区域与大小系数；后台和园区共用定位计算，缩放时接地位置固定。坐姿与横向趴姿均保持比例，旧版小平台按比例缩小；旧素材保留原有 88% 锚点布局。按人物地面位置排序遮挡，在视野内优先绘制最近 24 个画像，同时最多加载 4 张，支持时缩小到 256×256 缓存并换算裁切坐标；大地图缩得很小时不加载画像。链接过期会刷新园区地址并退避重试。

完整可复制提示词见 `portrait-art-guide.md`，后台也可一键复制。

## 小筑入口媒体

主人在“整理回忆”中逐张照片、逐段视频点击“在入口展示”，保存后沿用公开审核流程。点击小筑后的弹窗直接显示审核通过的选中媒体，照片可放大、视频由访客点击播放。未选择的媒体留在完整回忆页。审核员也可见每个“入口展示”标记。

入口接口只签发公开且已审核版本中的选中照片/视频，不读取草稿长文字，不返回私人音乐或文件 ID。更新待审时保持原公开版，关闭公开后停止向新请求返回媒体。照片/视频移除后也自动从入口选择中移除。切换小筑、关闭弹窗或退出页面时忽略过期请求结果。

## 声音及本轮界面调整

- 微信 `operateAudio:fail:audio is playing, dont play agin` 来自重复调用播放；现在播放开始前就锁定同一音源，收到结束事件后才能重播。已在播放的提示不再关闭音效，真实解码/下载错误仍报告。
- 回忆加载使用独立叶片图标，不继承全局空状态的狗头表情。
- 画像申请正面/侧面参考照使用等宽卡片和独立按钮样式；本地适配器检查 320、390、430px 无横向溢出。
- 后台相册入口使用 `chooseMedia` 的 `sizeType: ['original']`，再通过透明 Canvas 重绘并导出 PNG；不经过会丢失透明背景的普通照片压缩。部分设备若已转换为 JPEG，上传前会提示重新下载并保存透明 PNG 原图。
- 手机上的“文件”可先将 PNG 原文件保存到相册。已移除微信聊天文件选择入口；不要将 PNG 截图或转为 JPG。

## 画像已显示但无法确认安放（2026-11-12）

- 旧页面只依据两张 `image` 的 `bindload` 更新就绪状态；回调未更新时，即使画像和平台已经显示，也会被统一提示“请先上传并预览画像成品”。
- 上传后主动读取并校验两张预览图片。云端平台先下载到临时文件，再交给图片解码和预览使用；点击安放时也能补做检查。组件报告显示失败仍阻止确认，保留申请版本、上传凭证、内容摘要和尺寸核对。
- 区分未上传、正在加载、画像失败与平台失败，增加“预览已就绪”和“重试预览”。重试保留当前上传成品和缩放比例。每次尝试独立编号，旧图片回调不会影响新预览；离页取消等待，切换分类不会残留永久加载状态。
- 回归覆盖不触发图片加载事件也能确认、只加载一张时禁止确认、失败重试、旧回调、确认窗口错误、异步确认取消、分类切换和页面销毁。本地浏览器关闭加载回调后验证上传→105%缩放→确认链路，320/390/430px 无横向溢出。
- 本次修复仅涉及小程序审核页面，无需新增索引或更换画像素材。需要重新编译/上传小程序才会在真机生效；本地浏览器云接口为模拟，仍需微信真机复验，未部署。

## 审核写入空画像对象失败修复（2026-11-12）

- 真机错误：`Cannot create field 'bounds' in element {asset: null}`，发生在画像审核确认的数据库更新阶段。CloudBase 将普通对象 update 展开为嵌套字段写入，首次申请的 `asset: null` 无法接收这些字段。
- 画像申请的 `asset` 和园区位置的 `portrait` 改用 `db.command.set` 完整替换，仍在同一事务内更新审核状态、同园变更和通知。兼容原字段不存在、为 null 或旧画像包含过期字段。
- 同类问题也影响首次公开回忆的 `publicContent: null`，一并改为完整快照替换；从长故事改为短故事后，旧 `textFileId` 会移除，避免访客读到旧文字。
- 回忆/画像集成测试启用模拟 CloudBase 对象展开的更新规则：修复前复现 8 项失败，修复后专项 23/23 通过。新增首次安放与旧画像替换、85%大小、事务失败回滚后原凭证重试、重复确认不重复通知、长短文字版本替换检查。
- 生效方式：重新上传部署 `cloudfunctions/api` 云函数。已失败的数据库事务不会半途留下安放状态；当前页面若仍保留上传预览，可以在云函数更新后直接再次确认。无需数据迁移。本次未执行云端部署。
