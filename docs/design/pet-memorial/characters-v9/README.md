用户明确拒绝局部调色和移植手部，要求重新生成素材。本版通过 imagegen 技能自带 CLI 请求 `gpt-image-2.6-sunburst`，以已认可的第五版待机人物和第四版动作图作参考，重新生成完整八帧人物图。提示词要求浅金白色手掌、轻柔指缝阴影、连贯的肩膀—手臂—手腕—手掌。

完整提示词：`prompts/regenerate-complete-walk.txt`。模型输出：`raw/walk-generated.png`。用于播放的 `walk-sw.png` 与原始输出 SHA-256 完全相同，没有移植双手、局部调色、改变关节、逐帧缩放或程序补帧。后处理仅等分提取帧、合成检查图和 GIF。

实际图集 1248×832，4 列×2 行，单帧 312×416，行走每帧 125ms。待机继续使用第五版已认可素材。`preview.html` 可切换动作、放大手部、暂停和逐帧查看。
