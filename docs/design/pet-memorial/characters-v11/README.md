# 第十一版：男角色四方向动作候选

本轮补充右前方（se）、左后方（nw）、右后方（ne）的行走和待机。左前方（sw）沿用第十版 10.1 已修正高度的运行帧，逐像素不变。共八张图集、64 个实际动作帧，每组 4 列×2 行、8 帧，单帧 256×256，图集 1024×512，锚点 (128,230)。行走默认每帧 140ms，待机每帧 320ms。

素材位置：`output/imagegen/pet-memorial-v11/`。`preview.html` 为园区背景下四方向移动、松开保持朝向并待机、四方向同步对照、逐帧、半速、浅深底、手部和膝脚放大预览。方向按钮按住移动；键盘 Q/E/Z/C 对应左后/右后/左前/右前，WASD/方向键也可预览。此页仅检查动作，没有实现正式园区碰撞、寻路或权限逻辑。

交付：

- `cloud-upload/{walk|idle}-{sw|se|nw|ne}.png`：八张可供用户上传的真实透明图集。
- `frames/{direction}/{action}/01.png` 至 `08.png`：64 张独立帧。
- `{action}-{direction}.gif`、`four-directions.gif`：逐组及四方向循环预览。
- `{action}-{direction}-contact.jpg`：全部帧接触表。
- `manifest.json`：方向、切片、锚点、时长、来源与 SHA-256。
- `verification.json`：透明边界、图集切片与独立帧逐像素一致、帧唯一性、整帧位移及行走头部高度范围。
- `boy-four-directions-v11.zip`：图集、独立帧、预览、提示词及参数包。未采用原图和引导图留在本地 `raw/`、`reference/`，不放入交付 ZIP。

## 实际生成方式

沿用用户提供接口，使用 imagegen 技能自带 CLI edit 请求 `gpt-image-2.6-sunburst`。该名称为请求模型 ID，不代表独立验证了服务商内部映射。本轮没有换模型。凭据只从 Git 忽略的本地配置读取。

首轮直接从左前方行走转向，出现朝向没有转过来、后方偏侧面等问题，未采用。先生成后脑、披风背面的独立参考，再制作两组背向动作。右前方的步态引导以及右后方的方向引导使用了镜像参考；最终图集均由模型重新完整绘制，并非直接镜像旧运行图集。左后方的第一次迈步重复，随后参考右后方的相反朝向姿势重新绘制。

最终采用提示词在同目录 `prompts/`：`walk-se-refined.txt`、`walk-nw-final.txt`、`walk-ne-refined.txt`、`idle-se-final.txt`、`idle-nw-refined.txt`、`idle-ne-refined.txt`。`rear-reference.txt` 为本轮背面造型参考提示词，其余保留为未采用试制记录。

## 后处理与验证边界

`scripts/assets/package-memorial-v11.py` 保留真实 Alpha，跨组使用相同的源画布归一比例，没有逐帧独立缩放。新增行走沿用 10.1 修正方式，通过整帧平移稳定共同头部高度，避免最低鞋底的透视位置差使整个人物一高一低。待机按脚底基准定位。没有移植手部、局部调色、关节变形或程序补帧。源图切片边界检查、透明边界和最终图集一致性必须通过后才打包。

目前是**男角色四方向候选齐全**，不等于已经通过用户视觉验收。背面披风新增纹样、左右发型/挂饰等不对称细节、停走瞬间体态差异、背向步态的脚掌转折仍需结合慢速播放审阅。没有宣称跑步、女角色或正式园区接入已经完成；本轮未上传云端、发布或修改正式角色配置。
