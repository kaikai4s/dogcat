# 发布前修复与素材准备（2026-10-23）

AI问答页面统一调用 `ai.aiPetAssistant`。提问与模型回答都经过后端检测，沿用后端每用户每分钟10次的持久限流；检测失败的内容不会返回页面。页面限制300字、45秒超时，可重试，旧请求结果不会覆盖新请求。

服务记录摘要、海报及复制文案只引用订单状态、有效打卡数量、照片和实际备注。未记录的宠物状态、饮食、准时性、清洁情况和门锁安全不再生成肯定结论。海报不再自动盖“合格/审核通过”的结论章。

用户照片上传统一调用 `utils/image-upload`，支持JPG/PNG，自动缩小至最长边750像素、900KB以内；不合要求时继续压缩，失败则提示重新选择，不上传原大图。格式以图片解码信息为准，云路径后缀匹配实际格式。服务端仍执行图片内容检测，并拒绝超过1MB的文件。人物/宠物动作图集及建筑、植物素材属于严格尺寸的PNG图集，使用独立后台上传流程，不经过照片压缩，避免破坏帧布局。
