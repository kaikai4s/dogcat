# 发布前修复与素材准备（2026-10-23）

AI问答页面统一调用 `ai.aiPetAssistant`。提问与模型回答都经过后端检测，沿用后端每用户每分钟10次的持久限流；检测失败的内容不会返回页面。页面限制300字、45秒超时，可重试，旧请求结果不会覆盖新请求。

服务记录摘要、海报及复制文案只引用订单状态、有效打卡数量、照片和实际备注。未记录的宠物状态、饮食、准时性、清洁情况和门锁安全不再生成肯定结论。海报不再自动盖“合格/审核通过”的结论章。

用户照片上传统一调用 `utils/image-upload`，支持JPG/PNG，自动缩小至最长边750像素、900KB以内；不合要求时继续压缩，失败则提示重新选择，不上传原大图。格式以图片解码信息为准，云路径后缀匹配实际格式。服务端仍执行图片内容检测，并拒绝超过1MB的文件。人物/宠物动作图集及建筑、植物素材属于严格尺寸的PNG图集，使用独立后台上传流程，不经过照片压缩，避免破坏帧布局。

请将体验环境整个 `packagePlayground/2d/baseImage/` 目录（含全部子目录）按相同相对路径上传到上述生产存储。包括地面、建筑、庭院装饰、喷泉、人物、猫狗、车辆、排泄物和farm子目录素材。代码通过当前云环境自动选择根目录，历史默认素材ID在加载时会映射到当前环境；自定义形象及用户上传ID保留原值。

两端素材根映射分别位于 `miniprogram/packagePlayground/utils/asset-roots.js` 和 `cloudfunctions/api/services/playground-shared/asset-roots.js`，测试确保一致。服务端默认植物目录同时按部署环境选取；复制旧植物配置时默认素材根会规范化到当前环境。未配置的云环境不会静默回退体验素材。

用户已说明生产素材尚未上传，本次未执行素材迁移或云端部署。上传完成后需用正式环境体验路径确认所有目录及读取权限：首次进入庄园、切换人物/猫狗、车辆前后视图、院内地面、喷泉动画、植物阶段。代码和本地测试不能证明生产素材已经存在。

部署需整体上传新版api（含服务端shared素材映射）及小程序。生产环境仍需真实验证内容安全API、手机号授权、支付回调和退款；这些外部配置不通过本次代码修改自动完成。


## 本轮全项目复查修复

- 账号删除：用户资产、宠托师提现在 pending、approved、transferring、transfer_failed 状态均阻止软删除和彻底删除。检查数据库失败时停止删除；用户零钱收益台账保留，供历史对账和活动发奖查重。
- 宠物大赛现金奖：新发奖按月份使用固定收益记录 ID；事务内同时检查旧版本按宠物记录的月奖，换冠军、强制重结算与并发点击均不能产生第二份当月奖金。已发出的历史奖金不自动扣回。
- 宠物大赛展示：已锁榜月份按锁榜时的奖金快照展示；关闭期间结算的零奖金月份，重新开启活动或提高下一期奖金后仍保持零奖金与月度称号。零奖金时隐藏现金奖宣传海报，展示荣誉榜说明。
- 双重身份：兼任管理员的用户和宠托师可按订单归属访问自己的订单。查看其他人的订单仍须具备后台订单详情权限，普通宠托师预览仍执行性别筛选。
- 商城自动收货：按不可变记录 ID 分页扫描全部已发货订单，避免前 100 条新发货记录挡住后续超时订单；事务内复查订单与售后状态，仅将实际写入成功的订单报告为完成。
- 小区公开文本：保留微信地图选点流程，三个保存入口统一执行名称、地址、城市和区县文本检测及长度、经纬度检查。检测失败不写入；已有庭院的小区绑定规则继续生效。此次只加固后续保存，不批量改写既有小区数据。
- 配置导出：保存紧凑 JSON，和服务端 768KB 大小检查使用相同序列化方式，避免格式化缩进令导出文件无法再次导入；素材图片仍须单独迁移。

部署时整体更新 api 云函数及小程序。资金、内容安全、生产数据库查询等云端行为仍需在体验版本验证；本地测试不调用真实转账或内容检测服务。

本轮新增查询可按需补充非唯一索引：`user_asset_earnings` 的 `(sourceType 升序, monthKey 升序)` 用于兼容历史月奖查重，`mall_orders` 的 `(status 升序, _id 升序)` 用于自动收货游标分页。发奖唯一性由固定月份记录 ID 和事务保证，不依赖这两个普通索引。
