# 接单通知配置

接单通知适配微信「伴宠师接单通知」模板编号 44245。

在管理员后台系统设置中配置：

- 订阅消息 → 师傅接单模板：填写微信后台该模板的模板 ID，开启订阅消息后保存。
- 客服配置 → 客服电话：填写平台实际联系电话。发送及重试时读取此处最新配置。

字段对应：订单编号 character_string1、伴宠师名 thing2、联系电话 phone_number4、商品名称 thing5。姓名沿用项目现有展示规则，商品名称使用订单服务项目。

电话号码未配置时不调用微信发送接口，后台记录显示缺少平台客服电话；补好配置后可对跳过记录点击重试。接单业务本身不受缺少电话号码影响。

部署 api 并更新小程序后生效。将原接单模板换成 44245 后，用户需要在下单、订单详情或订阅中心同意新模板；原模板授权不会迁移到新模板。历史待发送的旧字段消息在实际发送时转换为新字段，原记录保留。

回归测试使用模拟微信发送接口，真实送达需在微信环境中完成用户授权和接单验收。
