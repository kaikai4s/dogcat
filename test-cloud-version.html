云函数部署状态检测

请在微信开发者工具中打开此页面，在控制台执行以下代码：

wx.cloud.callFunction({
  name: 'api',
  data: {
    action: 'getVersion'
  }
}).then(res => {
  console.log('云函数版本信息:', res.result)
  if (res.result && res.result.data) {
    alert('云函数版本: ' + res.result.data.version + '\n' + res.result.data.message)
  }
}).catch(err => {
  console.error('调用失败:', err)
  alert('调用失败: ' + err.errMsg)
})

预期结果

如果云函数已成功部署，应该返回：

{
  version: "2026-09-20 00:37",
  message: "修复 distanceFromCurrent 变量定义问题",
  timestamp: "2026-09-20T..."
}

部署步骤

  1. 打开微信开发者工具
  2. 找到 cloudfunctions/api 文件夹
  3. 右键点击 → 选择 "上传并部署：云端安装依赖"
  4. 等待部署完成（查看输出窗口）
  5. 部署成功后，在控制台运行上面的代码测试
